## Gateway Yeniden Başlatma

Her iki OAuth bağlantısı da başarılı olduktan sonra:

```bash
openclaw gateway restart
```

> Not: `OPENCLAW_SUPERVISOR_MODE=external` olduğu için bu komut hata verebilir. Control UI → Gateway sekmesi → Restart butonunu kullan.

## Kontrol

Bağlantı başarılı mı diye kontrol etmek için:

```bash
openclaw secrets list
```

Çıktıda `OPENAI_CODEX_TOKEN` ve `ANTHROPIC_CLAUDE_TOKEN` (veya benzeri) görünmeli.

- Bu sohbet (agent session) TTY desteklemez
